# 星糖花园撤离战

一个女生向、可爱风格的资源抽取射击小游戏。玩法保留 extraction shooter 的核心：进入地图、收集资源、处理敌人压力、在倒计时结束前撤离。

## 打开方式

直接在浏览器打开 `index.html` 即可。

也可以在当前目录启动一个本地服务：

```bash
python3 -m http.server 5173
```

然后访问 `http://localhost:5173`。

## 玩法

- 收集 8 颗星糖。
- 星糖收集满后，右侧花门会开启。
- 在倒计时结束前进入花门撤离。
- 小乌云会追击玩家，被碰到会降低心情值。
- 用泡泡法杖射击可以击退并消除小乌云。

## 操作

- 移动：`WASD` 或方向键
- 瞄准：鼠标移动
- 射击：鼠标左键或空格
- 重新开始：`R`

## 设计方向

- 原型类型：资源抽取射击小游戏
- 差异化目标用户：女生向、轻压力、可爱、治愈
- 主题包装：星糖、花园、泡泡法杖、小乌云、花门撤离
- 视觉实现：当前版本使用 Canvas 程序化绘制素材，无外部图片依赖
